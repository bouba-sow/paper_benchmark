# Paper draft (rewrite of 2026-11-10)

Storyline: memory and data constraints are associated with higher similarity to reading behavior, not to the brain
(Sec. 4.1); the behavioral advantage is not specific to DLT-hard words, which barely slow readers (4.2); it is carried by
rare words (4.3); constrained models gain no advantage on the multiple-demand network (4.4). Natural Stories x Podcast is in
Appendix C; training checkpoints in Appendix A; robust-z versions of every fit in Appendix B.

Build from this directory:

```bash
source /usr/share/Modules/init/bash
module load texlive/20240312
pdflatex -interaction=nonstopmode main_iclr2027.tex && bibtex main_iclr2027 && pdflatex -interaction=nonstopmode main_iclr2027.tex && pdflatex -interaction=nonstopmode main_iclr2027.tex
```

## Tables

All `sections/*_table.tex` matched-scale tables are generated by `build_rsa_tables.py` (run from the repository root:
`.venv/bin/python paperwriting/build_rsa_tables.py`); its docstring lists every source CSV. Main text: `summary_table.tex`
(Table 1: all datasets, DLT bins, frequency bins, language vs MD). Appendix: `summary_z_table.tex` (robust z; the all-datasets
z fit comes from `scripts/analysis/matched_scale_lineage_z.py`), `rsa_two_table.tex`, `md_dataset_table.tex`,
`rsa_ckpt{,_two}_table.tex`, `rsa_sameq_table.tex`. Ceiling tables: `build_supporting_tables.py` (overwrites several tables,
check its targets first). `rsa_main_table.tex`, `rsa_dlt_table.tex`, `rsa_freq_table.tex` and `appendix_direct.tex` are still
generated / kept but no longer included.
